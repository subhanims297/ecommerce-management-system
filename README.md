# Full-Stack E-Commerce & Inventory Management System

An enterprise-grade, decoupled full-stack web application designed to track warehouse inventory, handle product catalogs, manage customer orders, and provide real-time business insights.

## 🚀 Tech Stack

- **Backend:** C#, .NET 8/9, ASP.NET Core Web API, Entity Framework Core (EF Core)
- **Frontend:** React.js, TypeScript, Tailwind CSS, Redux Toolkit
- **Database:** Microsoft SQL Server
- **Authentication:** ASP.NET Core Identity, JWT (JSON Web Tokens)

## 📁 Repository Structure

- `/backend` - ASP.NET Core Web API, entity models, controllers, and data migrations.
- `/frontend` - React application, state management, components, and user interfaces.
